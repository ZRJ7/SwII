## Fig4 D-E GWAS



Scripts used to identify gene expression variation between last-instar wing bud tissues of the Sw and Lw phenotypes at the gene level.

RNA sequencing data are available from NCBI SRA under sccession: PRJNA1456943. Reads were aligned to the T. oceanicus genome v3 (ENA accession GCA_976985615).

The commend line below was used to generate the gene count matrix across samples:

prepDE.py -i . -l 150
