Dataset related to the manuscript entitled "A novel adaptation escapes evolutionary loss by recruiting life-history trade-offs".
1. Data description:
A detailed description of the dataset and experimental procedures is provided in the method section of the manuscript.
2. Types of files:
(1) .md: README file containing detailed instructions for data usage
(2) .r: R scripts used for statistical analysis and data visualization
(3) .csv: Raw and processed datasets
(4) .sh: Bash scripts for data processing and pipeline execution on Linux systems
(5) .py: Python scripts for data processing and analysis
3. Software required for use:
Spreadsheet software: Microsoft Excel
Statistical computing: R
Programming language: Python
Operating system: Linux (recommended for execution of shell scripts)
